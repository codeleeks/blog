### 조회하기

```sql
select c1.*, c2.*, c3.*, c4.*
from comments c1
	left outer join comments c2
		on c2.parent_id = c1.comment_id
	left outer join comments c3
		on c3.parent_id = c2.comment_id
	left outer join comments c4
		on c4.parent_id = c3.comment_id
```

- 컬럼을 추가하는 방식으로 깊이를 탐색.
- 카운트 쿼리 사용 어려움.

### 추가하기
 ```sql
 insert into comments (comment_id, parent_id, author, comment) values (1234, 7, 12, 'thanks');
```

### 수정하기

```sql
update comments set parent_id = 3 where comment_id = 6;
```

### 삭제하기

하위 항목 승격이나 재배치 없이 항상 삭제한다면 on delete cascade 쓰면 됨.

삭제 전 자식 승격을 하려면,

```sql
select parent_id from comments where comment_id = 6; -- returns 4
update comments set parent_id = 4 where parent_id = 6;
delete from comments where comment_id = 6;
```

### 재귀 쿼리로 조회하기

데이터베이스가 재귀 쿼리를 지원해야 함.

```sql
with recursive CommentTree
	(comment_id, parent_id, comment, depth, path)
as (
		select comment_id, parent_id, comment, 1 as depth, cast(comment_id as char(255)) as path
		from comments
		where parent_id is null
	union all
		select c.comment_id, c.parent_id, c.comment, ct.depth + 1 as depth, concat(ct.path, '->', c.comment_id) as path
        from CommentTree ct
        join comments c on (c.parent_id = ct.comment_id and ct.depth < 4)
)
select * from CommentTree;
```

- CommentTree라는 임시 테이블 생성
- 초기 레코드를 넣어주고, 이 레코드에 대하여 재귀적으로 수행. `union all`로 초기 레코드와 재귀 수행 결과를 합쳐줌.
- 예시 코드처럼 depth를 통해 탐색 step을 제한할 수 있음.
