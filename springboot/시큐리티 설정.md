## 스프링 시큐리티 설정

```java
package service.blog.config;

import lombok.AllArgsConstructor;
import lombok.extern.slf4j.Slf4j;
import org.springframework.boot.context.properties.ConfigurationProperties;
import org.springframework.context.annotation.Bean;
import org.springframework.context.annotation.Configuration;
import org.springframework.security.config.Customizer;
import org.springframework.security.config.annotation.method.configuration.EnableMethodSecurity;
import org.springframework.security.config.annotation.web.builders.HttpSecurity;
import org.springframework.security.config.annotation.web.configuration.EnableWebSecurity;
import org.springframework.security.config.annotation.web.configurers.AbstractHttpConfigurer;
import org.springframework.security.config.annotation.web.configurers.HeadersConfigurer;
import org.springframework.security.core.userdetails.User;
import org.springframework.security.core.userdetails.UserDetails;
import org.springframework.security.core.userdetails.UserDetailsService;
import org.springframework.security.provisioning.InMemoryUserDetailsManager;
import org.springframework.security.web.SecurityFilterChain;

@EnableWebSecurity
@EnableMethodSecurity
@Configuration
@AllArgsConstructor
@Slf4j
public class SecurityConfig {

    @Bean
    public SecurityFilterChain securityFilterChain(HttpSecurity http) throws Exception {
        http
                .headers(header -> header.frameOptions(HeadersConfigurer.FrameOptionsConfig::disable))
                .csrf(AbstractHttpConfigurer::disable)
                .formLogin(AbstractHttpConfigurer::disable)
                //search api는 필요
                .authorizeHttpRequests((req) -> req.requestMatchers("/posts/search").hasRole("ADMIN"))
                //다른 posts api는 no authenticated
                .authorizeHttpRequests((req) -> req.requestMatchers("/posts/**").permitAll())
                //그 외 다른 모든 API에 대해서 authenticated 체킹.
                .authorizeHttpRequests((req) -> req.anyRequest().authenticated())
                //다른 모든 api에 대하여 no authenticated. (authentication 체킹 안 함)
//                .authorizeHttpRequests((req) -> req.anyRequest().permitAll())
                .httpBasic(Customizer.withDefaults());

        return http.build();
    }

    @Bean
    public UserDetailsService users() {
        UserDetails user = User.builder()
                .username("id")
                //평문을 넣을 시에 {noop} prefix 필요. 안 그러면 auto configure 단계에서 exception 발생.
                .password("{noop}password_plaintext")
                .roles("USER", "ADMIN")
                .build();
        return new InMemoryUserDetailsManager(user);
    }
}

```

📌 전체 코드 개요
이 설정은 @Bean으로 등록되는 SecurityFilterChain 빈입니다. 이는 Spring Security 필터 체인을 구성하여 HTTP 보안 동작을 제어합니다.

🔐 각 설정의 의미
1. headers(header -> header.frameOptions(HeadersConfigurer.FrameOptionsConfig::disable))
설명: X-Frame-Options HTTP 헤더를 비활성화합니다.

목적: 일반적으로 클릭재킹 방지를 위해 iframe 내에 페이지를 삽입 못하게 막는데, 이걸 끄면 iframe에서 이 페이지를 embed할 수 있습니다. 예: H2 콘솔 등에서 필요.

2. csrf(AbstractHttpConfigurer::disable)
설명: CSRF(Cross Site Request Forgery) 보호를 비활성화합니다.

목적: REST API에서는 보통 세션 기반 인증을 쓰지 않으므로 CSRF 보호가 불필요하거나 오히려 장애가 될 수 있어 비활성화합니다.

3. formLogin(AbstractHttpConfigurer::disable)
설명: 기본 로그인 폼(form-based login)을 비활성화합니다.

목적: 자체 로그인 UI를 쓰지 않거나, 토큰 기반 인증(JWT 등)을 사용할 때 필요합니다.

🔐 인가 규칙 설정 (authorizeHttpRequests)
4. req.requestMatchers("/posts/search").hasRole("ADMIN")
/posts/search 요청은 ADMIN 역할을 가진 사용자만 접근할 수 있도록 설정합니다.

5. req.requestMatchers("/posts/**").permitAll()
/posts/** 경로에 대한 모든 요청은 누구나 접근 가능하게 허용합니다.

위의 /posts/search는 이미 특정 권한이 요구되므로 예외적으로 처리됩니다.

📌 주의: 이 라인이 /posts/search보다 아래에 오면 순서에 따라 오버라이드될 수 있습니다. 순서 중요!

6. req.anyRequest().authenticated()
위에서 정의되지 않은 모든 나머지 요청은 인증이 필요합니다.

즉, /posts/** 외의 요청은 인증된 사용자만 접근 가능하게 합니다.

(주석 처리된) req.anyRequest().permitAll()
주석으로 비활성화된 이 설정은 모든 요청을 허용합니다.

위의 설정과 반대되는 동작입니다. 테스트용이나 무제한 API 공개할 때 사용합니다.

7. .httpBasic(Customizer.withDefaults())
설명: 기본 HTTP Basic 인증을 사용합니다.

기능: 브라우저에서 사용자 이름/비밀번호를 요청하는 기본 팝업을 제공하여 인증 처리합니다.

대신: JWT나 OAuth2와 같은 고급 인증을 쓰지 않는 단순한 인증 방식입니다.
